# DSA: 25 – Online Course Recommendation Engine

## 📌 Project Overview

The **Online Course Recommendation Engine** is a Data Structures and Algorithms project designed to help students find suitable online courses based on their interests, skills, and learning level.

The project demonstrates how different **Data Structures and Algorithms** can be used to organize course information, search courses, rank recommendations, sort results, and represent relationships between courses.

---

## 🎯 Objectives

- Recommend suitable online courses to students.
- Organize course information efficiently.
- Search courses using Tree-based data structures.
- Rank courses using Heap and Priority Queue.
- Sort recommendations using Heap Sort.
- Represent relationships between courses using Graphs.
- Apply DSA concepts to a real-world problem.

---

## 🧠 DSA Concepts Used

- Binary Tree
- Tree Traversals
- Binary Search Tree (BST)
- BST Insertion, Deletion, Searching and Modification
- AVL Tree
- Binary Heap
- Priority Queue
- Heap Sort
- Threaded Binary Tree
- Graph
- Adjacency Matrix
- Adjacency List
